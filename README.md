> 一鍵解決現場教師「素養命題耗時、段考防作弊A/B卷出題困難、數值改編容易出現無解或畸零小數」的核心痛點！

## 📌 作品核心亮點與參賽競爭力

一般的題庫系統大多僅是關鍵字檢索，或是透過通用 AI 隨機換字，經常出現「改編後數值無解（如三角形不合三角不等式）」、「難易度失衡漂移」、「格式雜亂難以印刷」等致命問題。

**EduMorph 108** 針對教育部 108 課綱核心素養量身打造，具備四大創新技術特色：

| 評審看點 | EduMorph 108 核心技術解法 | 競賽加分點 |
| :--- | :--- | :--- |
| **多模態智能辨識** | 支援螢幕截圖直接 `Ctrl+V` 貼上或照片拖曳，視覺模型精確擷取幾何圖、函數式與題幹。 | 降低教師操作門檻，免除重新手打繁複數學公式的痛點。 |
| **動態數值約束守護 (Math Guardrail)** | 內建數值約束邏輯，確保更動之數字維持「整數解、特殊角、正數長度」，題目必定可解。 | 杜絕 AI 幻覺所產生的無解題或繁瑣畸零數字。 |
| **108課綱素養情境與人名置換** | 將傳統「小明、小華」替換為在地生活化情境（外送平台、高鐵捷運、永續減碳 SDGs、無人機）。 | 完美契合教育部 108 課綱「生活情境化」與「探究實作」指標。 |
| **認知等價性與跨題型轉換** | 自由切換【單選題】、【多選題】、【填充題】、【計算綜合題】；維持布魯姆認知階層。 | 讓教師自由依據評量目的進行題型轉化，單選題自動生成診斷性誘答項。 |
| **出版級 Word 試卷匯出** | 支援匯出【學生測驗卷 (A卷)】、【平行測驗卷 (B卷)】與【教師詳解評分卷】（.docx）。 | 符合高中段考標準版面、含分數、班級座號、作答留白區與 Rubrics 評分規準。 |

## 🚀 評審 3 分鐘快速體驗流程

本系統設計為**開箱即用**之現代化響應式 Web 應用程式：

1. **直接開啟**：
   - 用現代瀏覽器（Chrome、Edge 等）直接打開 `edu-exam-maker/index.html`。
2. **免 Key 快速展示**：
   - 點擊右上角 **「載入示範題目」**（內建國高中數學代數、理化運動學、幾何極值等典型素養大考題型）。
   - 點擊 **「執行 108 課綱智慧改題」**，即可在 1 秒內呈現改編後的生動題目與完整解析！
3. **體驗多模態截圖貼上**：
   - 在任何考卷或題庫截圖，回到系統直接按下鍵盤 `Ctrl + V`，立即看到圖片載入並啟動視覺辨識改題。
4. **平行卷與對照檢視**：
   - 切換標籤頁 **「改編題卷 (A卷)」** $\leftrightarrow$ **「平行題卷 (B卷)」**：體驗一鍵產出不同人名與數值、但考點完全相同的防作弊試題。
   - 切換 **「原題 vs 改編對照」** 與 **「素養向度評析」**：展示布魯姆認知階層雷達圖與評分規準 (Rubrics)。
5. **Word 試卷下載**：
   - 點擊右上角 **「匯出試卷 (.docx)」**，下載「學生測驗卷」或「教師詳解卷」，可用微軟 Word 直接開啟並列印！

## 🎯 108 課綱核心素養對齊指標

本系統在題目改編時，針對教育部核心素養三大面向、九大項目進行結構化對齊：
- **A 自主行動**：A2 系統思考與問題解決（計算綜合題的逐步邏輯推導）
- **B 溝通互動**：B1 符號運用與溝通表達（生活情境數學建模、LaTeX 數學語言表現）
- **C 社會參與**：C2 人際關係與團隊合作、永續生活實踐（SDGs 綠能環保、在地生活消費情境包裝）
